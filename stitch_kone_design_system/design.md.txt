# AutoHR Phase 0 Frontend Design Guidelines (LOCKED)

## Objective

Design a modern, minimal, and HR-friendly dashboard for the KONE AutoHR Demo.

The interface should prioritize **clarity**, **ease of use**, and **professional enterprise aesthetics** rather than flashy UI elements.

The primary users are **HR professionals**, therefore every screen should help them complete induction-related tasks with minimal effort.

---

# Design Inspiration

Reference Dashboard

The attached dashboard serves as a visual inspiration for:

- Overall spacing
- Card-based layout
- Sidebar structure
- Minimal color usage
- Typography hierarchy
- Enterprise dashboard feel

**This is only a design reference.**

The final UI must be customized for AutoHR and follow KONE branding.

---

# Design Philosophy

The application should feel like:

- Microsoft 365
- Atlassian
- Notion
- Linear
- Modern Enterprise Dashboard

NOT like

- Social media
- E-commerce
- Portfolio website
- AI chatbot
- Marketing landing page

---

# Core Design Principles

## 1. Minimal UI

The interface should contain only the information required by HR.

Avoid

- Fancy animations
- Glassmorphism
- Heavy gradients
- Oversized icons
- Decorative illustrations

Focus on usability.

---

## 2. Enterprise First

Every page should look suitable for internal company software.

Professional

Simple

Reliable

Clean

---

## 3. Low Cognitive Load

HR should understand the page within a few seconds.

Every page should answer:

- Where am I?
- What is the current session status?
- What should I do next?

---

## 4. Consistency

Maintain consistent

- Spacing
- Colors
- Buttons
- Cards
- Typography
- Border radius
- Icons

across the application.

---

# Final Design Goal (LOCKED)

The final AutoHR frontend should look like a modern enterprise dashboard inspired by the reference design while remaining aligned with KONE branding.

It should provide a clean, intuitive workspace where HR can:

1. View all induction sessions.
2. Create new sessions.
3. Upload presentation and employee files.
4. Invite employees using a meeting link.
5. Monitor session readiness.
6. Seamlessly transition into future AI-powered phases without requiring a UI redesign.

The design should emphasize professionalism, simplicity, and long-term scalability rather than visual complexity.
